# Versioned ML Model Serving and Observability

This project trains a reproducible binary classifier, packages its versioned artifact, and serves it through FastAPI with health/readiness probes, validated inputs, structured logs, Prometheus metrics, and integration tests. The executed synthetic-data training run achieved **0.8390 accuracy and 0.7190 F1** on a held-out 1,000-row test split.

> Independent portfolio project by Sebastián Astroza. Not affiliated with or endorsed by CERN.

## What this project demonstrates

- A model can be trained, serialized, loaded once at application startup, and used consistently for inference.
- FastAPI/Pydantic validation and stable JSON prediction contracts.
- Health, readiness, model metadata, prediction, and Prometheus endpoints.
- Request counters, inference latency histograms, structured JSON logs, and explicit 503 behaviour.
- CPU-only tests, a non-root Docker image, CI container build, and bounded Kubernetes resources/probes.

## Train and run

```powershell
& 'C:\Users\sebas\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m ml_model_serving_ops.train --output-dir artifacts
.\.venv\Scripts\uvicorn.exe ml_model_serving_ops.app:app --host 127.0.0.1 --port 8000
```

Linux uses a Python 3.12 virtual environment and the same module/uvicorn commands.

```powershell
Invoke-RestMethod http://127.0.0.1:8000/health
Invoke-RestMethod http://127.0.0.1:8000/ready
Invoke-RestMethod http://127.0.0.1:8000/model
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8000/predict -ContentType 'application/json' -Body '{"features":[0,0,0,0,0,0,0,0]}'
Invoke-WebRequest http://127.0.0.1:8000/metrics
```

## Results and limitations

See [RESULTS.md](RESULTS.md). The training data is generated by `sklearn.make_classification`; it is explicitly synthetic and contains no personal data. The model exists to validate operational mechanics, not to support a real decision process.
