# Validation Results

## Model artifact

- Model version: `1.0.0`
- Pipeline: StandardScaler + logistic regression
- Dataset: locally generated synthetic binary classification data
- Seed: 42
- Training rows: 4,000
- Held-out test rows: 1,000
- Test accuracy: 0.8390
- Test F1: 0.7190
- Feature contract: exactly eight finite numeric values

`artifacts/model.joblib` and `artifacts/metadata.json` were generated by the checked-in training command.

## API validation

The integration suite started the FastAPI lifespan and verified:

- `/health` returns 200 independently of model readiness.
- `/ready` returns 200 with artifacts and 503 without them.
- `/model` returns the versioned training metadata.
- `/predict` returns class, probability, and model version for a valid payload.
- malformed feature counts return 422 through Pydantic validation.
- a valid prediction request returns 503 when the model is unavailable.
- `/metrics` exposes request counters and inference-latency histogram data.

Final local checks: `ruff` passed, 2 pytest integration tests passed, `pip check` passed, and no credential-like assignments were detected. Pytest emitted one Starlette deprecation warning about its TestClient's current httpx integration; it did not affect the assertions.
